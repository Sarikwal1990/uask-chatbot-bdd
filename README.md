# U-Ask Chatbot QA — Quick Run Guide

## Prereqs
- Node.js + npm
- Python 3.10+ and venv created in project root (venv/)
- Activate venv: `.\venv\Scripts\Activate` (Windows) or `source venv/bin/activate` (mac/linux)
- Install Python deps: `pip install -r ai-engine/requirements.txt`
- Install node deps: `npm install`
